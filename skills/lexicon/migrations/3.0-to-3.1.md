# Schema 3.0 to 3.1

Schema 3.1 adds Markdown `heading` selectors to source links. The version boundary prevents schema-3.0 viewers from accepting a document and removing its heading selectors during unrelated edits.

For a valid schema-3.0 document, change only the root to `schema="3.1"`. Preserve every item, annotation, relationship, flow step, source link, and stable ID. Existing file, symbol, and line targets retain their meaning and identity; adding heading links is optional and requires inspected source.

Experimental Markdown links authored under schema 3.0 may already contain `heading` attributes. Preserve these attributes exactly and validate them using the current source checker. Never remove them to satisfy an older viewer. A heading is an anchor without `#`, exclusive with `symbol` and `line`; consult MODEL.md for the anchor rules.

Follow the common preservation, validation, and exact-byte backup instructions in README.md. Keep canvas.json, assets, conversations, and source files unchanged. Do not downgrade a schema-3.1 document for an older viewer; use a current viewer instead.
